A small, general widget pack to start from: a note card, a static HTML status board, a chart and two keys.

## What you get

- A Markdown note card.
- A status board drawn as static HTML (no script, nothing loaded).
- A bar chart.
- A **Screenshot** key and a **Scroll** dial.

Open any of them in Settings ▸ Widgets to see how it is made, then make a copy and change it. It works on any layout.
